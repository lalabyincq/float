# 浮岛记 子系统精细落地方案（基于三款同类游戏调研）

## 一、调研精华提炼

### 1. Monster Hunter —— 狩猎深度的标杆

| 机制 | 核心设计 | 对浮岛记的启示 |
|---|---|---|
| 部位肉质 | 每个部位对斩/钝/刺/元素有不同吸收率，**切武器才对** | 已有 `cutRate/pierceRate/bluntRate`，但**尾部应仅限斩击才能切断**，强化武器选择 |
| 睡眠爆发 | 怪物睡着后，**第一击物理伤害×2、爆炸×3**，是最大爆发窗口 | 当前 `sleepT` 仅做捕获前置，未加第一击加成——应补 `sleepFirstHit` 逻辑 |
| 捕获奖励 | 捕获比剥取更易出**稀有/独有素材**，鼓励"留活口" | 当前捕获只是不同掉落表，应加"捕获独有稀有素材（如狼牙→矿、鹿茸→晶）" |
| 疲劳/愤怒 | 疲劳=流口水迟缓、易中陷阱；愤怒=更激进、换招式 | 当前只有 `graze/alert/chase/flee`，缺"疲劳(流血累)"与"愤怒(连续被打)"状态 |
| 部位破坏 | 破坏部位给额外/稀有掉落，部分稀有素材只能靠破坏 | 已有 `partBroken`+`breakDrop`，应确保破坏掉落与普通剥取**分离且稀有** |
| 怪物食性 | Deviljho 必须不停进食、Odogaron 食腐——生态驱动行为 | 当前鹿/狼无食性/领地，应加 `diet` 与 `homeRange` |

### 2. The Hunter: Call of the Wild —— 感知追踪的拟真标杆

| 机制 | 核心设计 | 对浮岛记的启示 |
|---|---|---|
| 风锥气味 | 罗盘显示风向锥，**背风=气味前飘=被早发现**；迎风=能贴脸 | 已有 `windAng`+嗅觉判定，但缺**玩家自身气味可视化**（在地面画气味云） |
| 粪便线索 | 长轨迹中点有粪便，**粪便告诉你动物是否还在附近** | 当前只有足迹/血迹，应加 `dropping` 痕迹，带时间戳信息 |
| Need Zones | 动物按固定时间去饮水/进食/休息/社交区，**饮水区最精确** | 动物当前随机漫游，应加 `needZone` 与按时间调度的行为 |
| 姿态分级 | 卧>蹲>走，噪音递减但速度递减，卧姿最隐蔽也最脆弱 | 当前只有 walk/sneak 二态，应加 `crouch`（中速/中噪）与 `prone`（极慢/极低噪） |
| 狩猎压力 | 区域猎杀产生压力，**其他动物迁徙离开该区** | 当前动物无限刷新，应加区域 `huntPressure` 导致该区域动物减少/远离 |
| 物种特异性叫声 | 不同笛只吸引对应物种，靠风传播 | 当前骨哨吸引所有鹿、吓跑所有狼，应改为**物种特异性** |
| 器官瞄准窗口 | 心/肺在前腿后方、胸口 1/3 处，需找宽侧面 | 已有 `heart` 部位，但无"侧面射击"角度奖励——应加**角度/朝向命中率修正** |
| 猎物评分 | 正确弹药+正确命中=高分，决定掉落品质 | 可加"狩猎品质评分"影响掉落数量与稀有度 |

### 3. ARK: Survival Evolved —— 驯服长线的标杆

| 机制 | 核心设计 | 对浮岛记的启示 |
|---|---|---|
| 独立眩晕值 | Torpidity 与 HP 分离，**填满眩晕才晕，不能打死** | 当前 `sleepT` 兼任眩晕，应拆出独立 `torpor` 条 |
| 击晕 vs 和平 | 击晕驯服（打晕喂食）/ 和平驯服（靠近喂食，不能攻击） | 应加两种驯服路径，草食动物支持和平驯服 |
| 驯服有效性 | 越喜欢的食物越快、加成越高，**长时间不喂有效性衰减** | 应加 `tameEffectiveness`，吃对食物涨、衰减掉 |
| 生物食性/性情 | 食肉/食草；被动/防御/主动攻击 | 应加 `diet` 和 `temperament` 驱动 AI |
| 生物等级/属性 | HP/耐力/食物/负重/近战/速度/眩晕 每点不同 | 应加动物 `level` 与属性随机，等级影响掉落与驯服难度 |
| 驯服后用途 | 坐骑/驮运/守卫/生产（鞍具解锁） | 驯服后可作为**驮兽/守卫/猎犬**，对应 DESIGN.md "装备靠族人帮" |

## 二、子系统落地方案

> 所有改动均落在 `index.html` 单文件内，标注**行号锚点**对应当前代码位置。

### 子系统 A：狩猎系统深化（优先级 高）

**现状**：5 部位独立 HP、武器类型吸收率、毒/睡眠/流血、陷阱+麻醉捕获。
**差距**：缺尾部斩击专属、睡眠第一击爆发、捕获稀有素材、疲劳/愤怒状态、破坏掉落分离。

#### A1. 尾部仅限斩击切断（怪猎核心差异化）

- `PART_DEFS` 中给 `hindLeg`（或新增 `tail` 部位）加 `severOnly:true`。
- `takeDmgPart` 内：若 `part.severOnly && weaponType!=='cut'`，则**不扣部位 HP**（只掉血），破坏不触发。
- 破坏后掉落 `breakDrop` 中加稀有素材（鹿尾筋→骨×3、狼尾→皮×2）。

```js
// PART_DEFS 新增字段示例
{key:'tail', label:'尾', ..., cutRate:1.0, pierceRate:0.3, bluntRate:0.2,
 partHp:20, severOnly:true, breakDrop:{bone:3}, breakEffect:'slow50'}
// takeDmgPart 内
if(part.severOnly && weaponType!=='cut'){ /* 不扣 partHp */ }
```

#### A2. 睡眠第一击爆发（怪猎最大爽点）

- `Animal` 加 `sleeping` 标志（`sleepT>0`）。
- 受到伤害时，若 `sleeping` 且是**首次命中**，伤害 `×2`（矛）/ `×3`（爆炸类，暂用斧重击）。
- 命中后唤醒（`sleepT=0`），只触发一次。
- 应用：先麻醉让动物睡，再用满级矛一击爆头。

```js
takeDmgPart(d,part,game,weaponType){
  let finalDmg=d;
  if(this.sleepT>0){ finalDmg*= (weaponType==='cut'?3:2); this.sleepT=0; game?.showMsg('★睡眠爆发!'); }
  ...
}
```

#### A3. 捕获独有稀有素材

- `doTranq` 捕获成功时，按物种给**独有素材**：
  - 鹿：`crystal+1`（鹿茸结晶，剥取不掉）
  - 狼：`ore+1`（狼牙矿化，剥取不掉）
- 与当前 `bone/hide/meat` 基础掉落叠加，强化"捕获>击杀"的策略价值。

#### A4. 疲劳 / 愤怒 双状态

- **疲劳**：`bleed>0.5` 或 `hp<35%` 时进入，移速 `×0.7`、感知 `×0.6`、陷阱命中率提升、不再愤怒。
- **愤怒**：连续被命中 ≥3 次（`hitStreak`）或 HP<60% 时进入，移速 `×1.2`、攻击间隔 `×0.7`、不再 flee（除非 HP<20%）。
- 愤怒时头部吸收率下降（`pierceRate` 临时 ×0.6），鼓励打腹/腿。
- UI 显示状态图标（怒=🔥、疲=💧）。

#### A5. 破坏掉落与剥取分离

- `partBroken` 后立即给 `breakDrop`（不进尸体，即时进包或掉地上）。
- 尸体剥取 `part.drop` 保持基础掉落。
- 这样"破坏部位"有即时正反馈，不等采集。

### 子系统 B：感知与追踪深化（优先级 高，当前 in_progress）

**现状**：风向、噪音、足迹/血迹、骨哨。
**差距**：缺玩家气味可视化、粪便时间线索、Need Zones、姿态分级、狩猎压力、物种特异叫声、角度修正。

#### B1. 玩家气味云可视化（荒野的呼唤风锥）

- 每 1 秒在玩家身后（逆风方向）生成 `scent` 痕迹，随风向漂移 3~5 格后消散。
- 动物嗅觉检测改为：**动物是否在气味云范围内** + 风向，而非纯距离。
- 绘制：地面半透明蓝色斑块沿风向延伸。

```js
// update 内
this.scentT=(this.scentT||0)+dt;
if(this.scentT>=1){ this.scentT=0;
  const sx=this.player.x-Math.cos(this.windAng)*0.5, sy=this.player.y-Math.sin(this.windAng)*0.5;
  this.scents.push({x:sx,y:sy,life:8});
}
// 动物嗅觉：扫描 scents 数组，downwind 且距离<嗅觉范围 → alert
```

#### B2. 粪便线索带时间信息

- 动物每 15 秒留一个 `dropping`，带 `age` 时间戳。
- 玩家靠近粪便时显示信息："新鲜(<30s)/较久(<2min)/很久(>2min)"，判断动物是否还在附近。
- 粪便比足迹持续更久（120s），是长距离追踪锚点。

#### B3. Need Zones 时间调度

- 每只动物有 `needZones:{drink:[{x,y}], eat:[{x,y}], rest:[{x,y}]}`。
- 按 `dayTime` 调度：
  - 0~25（清晨）→ 饮水（去水源）
  - 25~50（白天）→ 进食（草地随机点）
  - 50~75（黄昏）→ 饮水
  - 75~100（夜晚）→ 休息（随机点，不动）
- 玩家可观察规律，在饮水区蹲守。

#### B4. 姿态三档：walk / crouch / prone

- `posture` 字段：`walk`（默认，noise=0.3，speed=3.2）、`crouch`（noise=0.15，speed=2.0）、`prone`（noise=0.05，speed=0.8，不可攻击/投矛）。
- 潜行按钮改为循环切换：walk → crouch → prone → walk。
- `prone` 时近战/投矛禁用（必须起身），模拟真实伏击。

#### B5. 狩猎压力区

- 击杀动物时，在击杀点半径 5 格内 `huntPressure` 累加。
- 压力高的区域：动物生成率下降、生成距离更远、路过动物加速离开。
- 压力随时间衰减（每 60s -1），鼓励玩家轮换狩猎区，不蹲点刷。

#### B6. 物种特异性叫声

- 骨哨按当前装备/选择分两种：`deerCall`（吸引鹿）、`wolfCall`（吸引狼——高风险高回报，狼群朝你聚集）。
- 叫声范围受风向影响（顺风传播远）。

#### B7. 角度/朝向命中修正

- 投矛命中部位时，若**动物正侧身**（玩家朝向与动物朝向夹角 70~110°），伤害 `×1.2`，部位 HP 扣减 `×1.2`。
- 正面/背面命中无加成。鼓励绕侧射击心/肺区。

### 子系统 C：生存系统微调（优先级 中）

**现状**：饥/渴/温 + 火堆 + 昼夜。已较完整。
**差距**：与狩猎/天气的联动可加强。

#### C1. 体温与战斗联动

- 低温（<30）时近战伤害 `×0.8`、耐力恢复 `×0.7`。
- 高温（>80）时口渴消耗 `×2`（已有），且耐力上限 `×0.8`。
- 火堆旁恢复体温（已有），新增：**火堆旁可烤肉**，熟肉比生肉饱食 +15、无腐坏风险。

#### C2. 伤口感染（远期，可选）

- 被狼咬伤有概率 `infected`（10%），持续掉血直到吃草药（新增资源）或回营地休息。
- 增加战斗风险与回营动机。

### 子系统 D：驯服与长线（优先级 低，当前 pending）

**现状**：无。
**落地**：引入 ARK 式驯服，作为 DESIGN.md "装备靠族人帮" 的兽力延伸。

#### D1. 独立眩晕值 `torpor`

- `Animal` 加 `torpor`（0~100），与 `hp` 分离。
- 麻醉球、钝击（斧背/石锤）造成 `torporDamage`，同时少量掉 HP。
- `torpor>=100` → `sleepT` 触发（晕倒），HP 不归零。

#### D2. 两种驯服路径

- **击晕驯服**（狼/食肉）：打晕 → 喂偏好食物（狼→生肉/鱼）→ `tameProgress` 涨满。
- **和平驯服**（鹿/食草）：潜行靠近 → 手持果实/草 → 喂食（不攻击）→ 涨进度。
- 驯服过程中被攻击或跑远 → 进度重置。

#### D3. 驯服有效性 `tameEffectiveness`

- 喂对食物（鹿→果、狼→生肉）有效性高、进度快；喂错（鹿喂肉）有效性低、进度慢。
- 不喂时有效性随时间衰减，最终驯服的属性加成降低。
- 高有效性驯服的动物属性 +20%。

#### D4. 驯服后用途

- **鹿**：驮兽（增加玩家携带量，或跟随驮资源）。
- **狼**：守卫/猎犬（跟随玩家，攻击敌对动物）。
- 需制作对应"鞍/项圈"（消耗皮+骨）解锁跟随。
- 对应 DESIGN.md：独行有上限，需要伙伴帮。

#### D5. 动物等级与属性

- 生成时随机 `level`（1~5），影响 HP、速度、掉落数量、驯服难度。
- 等级 5 的动物有独特外观（更大/变色），掉落稀有素材。
- 玩家可通过观察足迹/粪便推测等级（高等级足迹更深）。

### 子系统 E：体验打磨（优先级 低）

**现状**：昼夜、视野、火堆光效。
**落地**：天气、UI、生态。

#### E1. 天气：雨/雾

- `Weather` 类：`clear/rain/fog`，每 120~300 秒切换。
- 雨：视野 -2、口渴不再降、体温下降加快、火堆燃烧加速。
- 雾：视野 -3、动物感知范围 -3（双方都瞎，利于潜行）。
- 雨时玩家身上无气味（气味被冲散），利于靠近但无法追踪。

#### E2. 小地图与状态图标

- 右上角小地图：显示已探索地形、动物红点、火堆、营地。
- 动物状态图标：怒/疲/睡/毒/流血/陷阱 一目了然。
- 风指示器已有，加气味锥提示。

#### E3. 生态：食性与地盘

- `diet:herbivore/carnivore`。食肉动物会主动攻击食草动物（狼追鹿），形成生态链。
- `homeRange`：动物有活动中心，远离时倾向返回。
- 狼击杀鹿后会进食（恢复少量 HP），玩家可抢食或等狼离开再捡。

## 三、实施步骤（依赖顺序）

> 编号对应子系统内小节，按依赖先后排列。

1. **A1 尾部斩击专属** + **A5 破坏掉落分离**（纯数据/函数改动，独立）
2. **A2 睡眠第一击爆发**（依赖 `sleepT`，已有）
3. **A3 捕获稀有素材**（纯掉落表改动）

6. **B7 角度命中修正**（小改动，独立）
7. **B1 玩家气味云**（影响嗅觉判定，需改 `Animal.update`）
8. **B2 粪便线索** + **B3 Need Zones**（改动物行为调度）
9. **B5 狩猎压力** + **B6 物种特异叫声**（改生成与哨子）
10. **C1 体温战斗联动**（小改动）
11. **D1 眩晕值** + **D2 驯服路径** + **D3 有效性** + **D4 用途** + **D5 等级**（驯服整包，依赖 A 的状态系统）

**建议批次**：第 1 批（A1~A4 + B4 + B7）作为狩猎体验强化；第 2 批（B1~B3）追踪深度；第 3 批（B5~B6 + C1）生态联动；第 4 批（D1~D5）驯服长线；第 5 批（E1~E3）打磨。

- **A1**：用矛打鹿尾不破坏，用斧打鹿尾触发 `★尾破坏!` 且掉落骨×3。
- **A2**：麻醉鹿至睡眠，投矛命中显示 `★睡眠爆发!` 且伤害为基础 2 倍。
- **A3**：捕获鹿获得 `crystal+1`，击杀剥取无 crystal。
- **A4**：狼连续被打 3 次显示 🔥 且移速加快；狼流血过半显示 💧 且变慢、易中陷阱。
- **B1**：逆风靠近鹿不被发现，顺风靠近鹿提前逃跑；地面可见蓝色气味云。
- **B2**：跟随鹿足迹找到粪便，显示"新鲜/较久"。
- **B4**：切换 prone 后噪音最低但投矛按钮禁用。
- **B7**：绕到鹿侧面投矛伤害 ×1.2。
- **D1~D4**：打晕狼喂生肉，进度涨满后狼跟随玩家并攻击其他狼。
- **回归**：现有鹿/狼 AI、采集、昼夜、火堆功能不破坏。

## 五、风险与对策

| 风险 | 对策 |
|---|---|
| 单文件 `index.html` 继续膨胀，可维护性下降 | 每个子系统改动用注释分区（`// === 子系统A ===`），函数保持短小；驯服/天气可抽类 |
| 状态过多导致 AI 状态机复杂 | 疲劳/愤怒用标志位叠加在现有状态上，不新增顶层状态分支 |
| 驯服系统过大挤占 MVP | D 阶段整体标"远期"，先只做 D1 眩晕值为捕获系统服务，D2~D5 按需 |
| 移动端性能（气味云/粪便/天气粒子） | 痕迹数量设上限（scent≤20、dropping≤30），天气用全屏半透明遮罩而非粒子 |
| 破坏掉落即时进包与"采集"流程冲突 | 破坏掉落掉地上（`tracks` 同级 pickup），玩家走过去捡，保持采集仪式感 |
